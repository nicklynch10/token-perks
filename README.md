# Token Perks

The best AI offers. The catches, upfront.

Token Perks is a deals-first publication covering AI tools and services: the offers worth taking, and the fine print you should know before you pay.

## Stack

- [Next.js](https://nextjs.org) 16 with static export
- Tailwind CSS v4
- Deployed to Amazon S3 + CloudFront at [token-perks.com](https://token-perks.com)

## Development

```bash
npm install
npm run dev     # start the dev server
npm run build   # production build; static export is written to out/
```

## Pricing data

Price and offer data under `content/` carries a `verified_at` date. Offers and pricing change frequently — always re-verify on the vendor's site before paying.
